Чекап базы лицензий и ПО

Бесплатный инструмент самодиагностики: загрузите фрагмент выгрузки из вашей системы учета ПО и за минуту получите индекс качества базы и список типовых проблем.

  • Работает локально в браузере — данные никуда не отправляются
  • Поддерживает .xlsx, .csv и .xml до 200 строк
  • Показывает дубли, разнобой названий, версий и дефекты записей

Фрагмент выгрузки из системы учета ПО

.xlsx · .csv · .xml · до 200 строк

Данные обрабатываются локально в вашем браузере и никуда не передаются.

Что можно загрузить

  • Выгрузку из ИТМен, SCCM, Altiris и других систем учета ПО
  • Таблицу Excel с колонками: название ПО, версия, издатель
  • CSV-файл из CMDB, ITSM или SAM-системы
  • Фрагмент до 200 строк — достаточно для экспресс-оценки
Совет: если в файле нет заголовков колонок, первые три столбца будут считаться названием, версией и издателем.
