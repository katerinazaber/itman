Как это работает

1

Подключение к RedVirt

  • Задача «Сбор данных через REST API» с сенсорами для API RedVirt / oVirt
  • Учетные данные с платформой RestAPI в справочнике учетных данных
  • Несколько инсталляций RedVirt добавляются как отдельные цели подключения
2

Сбор и нормализация данных

  • Сбор данных о виртуальных машинах и инвентаризация хостов RedVirt
  • При необходимости дополнительный опрос гостевых систем, в том числе на РЕД ОС
  • Приведение данных к единому формату вместе с другими гипервизорами
3

Передача данных

  • Передача готовых очищенных данных в CMDB, ITSM, ITAM или SAM

Что мы собираем

RedVirt дает состав виртуальной инфраструктуры на базе KVM: ВМ, хосты и кластеры. Этого мало для полной инвентаризации, поэтому ИТМен при необходимости дополнительно опрашивает сами виртуальные машины.

Из RedVirt

  • Виртуальные машины и хосты KVM
  • Кластеры и пулы ресурсов
  • Конфигурация виртуальной машины: CPU, RAM, диски, состояние

С гостевых систем

  • Конфигурация железа и сетевые параметры
  • Установленное ПО и версии для контроля лицензий и учета ITAM/SAM
  • Пользователи и учетные записи на виртуальной машине

Работа со смешанной виртуализацией

  • RedVirt, zVirt, VMware и Hyper-V в одной нормализованной базе
  • Несколько инсталляций RedVirt как отдельные источники
  • Настраиваемые сенсоры REST API под объекты и поля API

Частые вопросы

Как ИТМен подключается к RedVirt?

Через задачу «Сбор данных через REST API»: адрес сервера RedVirt, учетные данные RestAPI и сенсоры к API RedVirt / oVirt.

Нужны ли агенты на каждую виртуальную машину?

Для сбора метаданных ВМ из RedVirt агенты на гостевых системах не обязательны. Более глубокая инвентаризация гостей идет через сетевую или локальную задачу.

Можно ли совмещать с zVirt и VMware?

Да. Данные из RedVirt, zVirt, vCenter и SCVMM сводятся в единую нормализованную базу.

Какие права нужны для подключения?

Учетная запись с правами администратора для доступа к API RedVirt и учетные данные с платформой RestAPI в ИТМен.

Работает ли сбор в закрытом контуре?

Да. Подключение к RedVirt выполняется внутри периметра, данные передаются по защищенным каналам.

Подходит ли ИТМен для учета ВМ при миграции на RedVirt?

Да. ИТМен собирает актуальный список виртуальных машин и хостов из RedVirt и других гипервизоров. Это удобная основа для планирования и контроля перехода.

Чем ИТМен отличается от выгрузок из консоли РЕД Виртуализации?

Это российская программа для инвентаризации RedVirt из реестра ПО: сводит данные из нескольких источников виртуализации, нормализует их вместе с физическими узлами и передает в CMDB/ITSM без ручного экспорта.
