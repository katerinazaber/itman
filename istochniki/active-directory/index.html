Как это работает

1

Подключение к Active Directory

  • Подключение к контроллеру домена по LDAP или LDAPS
  • Выбор нужных OU
  • Загрузка состава каталога и связей учетных записей с устройствами
2

Сбор и нормализация

  • Сбор карточек из каталога
  • Дополнительный сбор данных с самих узлов
  • Сверка с сетью
  • Приведение всех данных к единому формату
3

Передача данных

  • Готовые очищенные данные уходят в CMDB, ITSM, ITAM или SAM

Что мы собираем

Каталог AD дает список компьютеров, пользователей и структуру домена. Этого мало для полной инвентаризации, поэтому ИТМен дополнительно опрашивает сами узлы.

Из каталога Active Directory

  • Компьютеры, пользователи, организационные единицы (OU) и группы
  • Связь учетной записи пользователя с конкретным устройством
  • Расположение, описание, базовая информация об ОС

С самих узлов

  • Конфигурация: процессор, память, диски, сетевые адаптеры (IP, MAC, DNS-имя)
  • Установленное ПО и версии, для контроля лицензий и учета ITAM/SAM
  • Устройства, которые есть в сети, но не заведены в AD, и наоборот

Работа с масштабом

  • Несколько доменов и лесов одновременно, в единой базе
  • Агентный и безагентный сбор: WinRM, WMI, SSH, SNMP

Соответствие требованиям информационной безопасности

Работает в закрытых периметрах, без выхода инфраструктуры в интернет

Частые вопросы

Чем сбор данных через AD отличается от аудита Active Directory?

ИТМен инвентаризирует ИТ-активы: оборудование, ПО и пользователей на основе данных домена. Аудит прав доступа и настроек безопасности AD он не проводит.

Нужны ли агенты для сбора?

Поддерживается и агентный, и безагентный сбор, в зависимости от инфраструктуры и политик.

Можно ли собирать данные из нескольких доменов?

Да. Данные из нескольких доменов и лесов сводятся в единую нормализованную базу.

Видит ли ИТМен устройства вне домена?

Да. Дискаверинг находит и неучтенные устройства, которые не заведены в Active Directory.

Является ли Инферит ИТМен системой CMDB?

Нет. ИТМен собирает и нормализует данные, а затем наполняет ими CMDB и ITSM. Он не заменяет эти системы.

Можно ли синхронизировать не весь домен, а отдельные OU?

Да. Область синхронизации задается по организационным единицам. Это удобно для филиалов и пилотных контуров.

Поддерживается ли защищенное подключение к каталогу?

Да. Для работы с контроллером домена используется LDAP, при необходимости, защищенный канал LDAPS.

Работает ли сбор в закрытом контуре без выхода в интернет?

Да. ИТМен разворачивается внутри периметра и собирает данные из Active Directory без внешнего подключения, с передачей по защищенным каналам.
