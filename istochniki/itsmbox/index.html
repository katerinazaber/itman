Частые вопросы

ИТМен и ITSMbox — это одно решение?

Два продукта в одной экосистеме: ИТМен даёт данные, ITSMbox — процессы ITSM/ITAM/SAM.

Зачем два продукта, если в ITSM есть инвентаризация?

Специализированный дискаверинг точнее и глубже встроенного модуля. От качества данных зависит всё остальное.

Нужно ли сверять данные вручную после внедрения?

Нет. ИТМен обновляет базу автоматически.

Подойдёт для импортозамещения?

Да. Замена зарубежного стека без потери полноты данных об активах.

Работает в закрытом контуре?

Да. Оба продукта внутри периметра, без внешнего интернета.
