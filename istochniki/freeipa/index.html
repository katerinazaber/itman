Что ИТМен собирает из FreeIPA

Через LDAP ИТМен получает данные о пользователях FreeIPA и устройствах, доступных им под своими учетными записями. Для более полной инвентаризации ИТМен может дополнительно собирать данные с самих устройств.

Из каталога FreeIPA

  • Пользователи и устройства — учет пользователей и хостов в FreeIPA
  • Информация о LDAP-пользователях, имеющих доступ к устройству

С самих узлов

  • Конфигурация: процессор, память, диски, сетевые адаптеры (IP, MAC, DNS-имя)
  • Инвентаризация ПО и его версии на инвентаризируемых Linux-устройствах

Работа с Linux-инфраструктурой

  • Домены и хосты на разных Linux-дистрибутивах в одной нормализованной базе
  • Удаленная инвентаризация Linux-устройств по SSH или локальная инвентаризация с помощью агента

Сетевая инвентаризация позволяет обнаруживать устройства независимо от их наличия в каталоге FreeIPA.

Частые вопросы

Чем FreeIPA отличается от Samba и Active Directory?

Со стороны ИТМен принцип одинаковый: для Active Directory, FreeIPA и Samba AD используется задача сбора данных по LDAP. Полученная информация может дополнительно обогащаться результатами локальной и сетевой инвентаризации.

Можно ли одновременно вести учет по FreeIPA и Windows AD?

Да. ИТМен поддерживает получение данных из Active Directory, FreeIPA и Samba AD по LDAP. Для LDAP-задачи можно настроить несколько целей инвентаризации.

Нужны ли агенты для сбора?

Для выполнения LDAP-задачи используется агент ИТМен с функцией сетевой инвентаризации. Устанавливать агент на каждое устройство, данные о котором получаются из каталога, не требуется.

Видит ли ИТМен устройства вне домена?

Да. Сетевая инвентаризация позволяет сканировать заданные подсети и IP-диапазоны и обнаруживать устройства независимо от данных FreeIPA.

Работает ли сбор в закрытом контуре?

Да. ИТМен разворачивается внутри периметра и собирает данные без внешнего подключения, с передачей по защищенным каналам.
