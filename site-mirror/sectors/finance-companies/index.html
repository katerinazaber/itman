Инферит ИТМен для финансовых компаний

Автоматическая инвентаризация и контроль ИТ-инфраструктуры с соблюдением требований КИИ (ФЗ-187), ЦБ РФ и ГОСТ Р 57580.1

  • Актуальные и нормализованные данные об ИТ-активах для аудита, отчетности регуляторам и управления рисками

  • «Чистые»  данные в CMDB для  ITAM, SAM банков, страховых и финтех

  • Полный контроль многофилиальной ИТ-инфраструктуры

Год бесплатной техподдержки

Вам подойдет решение, если:

Нужны достоверные данные об ИТ-активах для соответствия требованиям КИИ (ФЗ-187), ГОСТ Р 57580.1 и отчетности перед ЦБ РФ

Сложно обеспечить полный контроль ИТ в распределенной инфраструктуре: филиалы, банкоматная сеть, POS-терминалы и т.д.

Нет прозрачного ITAM для банков, страховых, финтеха: непонятен объем используемого оборудования и ПО для планирования бюджета и управления и затратами

Аудит информационной безопасности и подготовка к проверкам регуляторов занимают много времени и ресурсов

Функциональные возможности

Агрегация и нормализация данных

Агрегация любых выбранных параметров по ИТ-активам из сторонних систем и источников данных
Гибкие настройки параметров агрегации любых данных
Приведение данных к единому формату
Сбор данных из труднодоступных источников (в закрытых сегментах сети)
Агрегация ранее не собираемых специализированных данных

Обогащение и контроль ПО

Точное количество установок нормализованного ПО (без разношерстных записей)
Реальные данные о неиспользуемых и устаревших конфигурациях с историей изменений
Редактор правил распознавания и обогащения ПО
Обогащение ПО неинвентарной информацией из Библиотеки ПО (300 000+ наименований)
Обогащение информацией по параметрам расположения и типу оборудования

Отчетность и аналитика

Отчеты по ИТ-активам в различных срезах с возможностью выгрузки
Отчеты по использованию ПО, портов и других объектов с аналитикой по заданному периоду

Клиент хотел наладить эффективное взаимодействие бизнесом и ИТ-подразделением, повысить эффективность ITSM-процессов. Нужно было решить проблему отсутствия нормализации безы данных управления конфигурациями (CMDB).

Перед клиентом стояла задача ускорить процесс выявления и удаления запрещенного ПО на рабочих компьютерах сотрудников, отладить и автоматизировать процесс перераспределения текущих лицензий на дорогостоящее ПО.

Страхование
Повысили эффективность управления ИТ-активами заказчика на 80%
Страховой брокер Remind обратился с запросом на внедрение инструмента для учета рабочих станций, с возможностью добавления серверов и сетевого оборудования. Компания рассматривала различные решения, включая ManageEngine, и искала систему класса CMDB.
