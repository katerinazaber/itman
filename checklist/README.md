# Лендинг: бесплатный экспресс-аудит ИТ-инфраструктуры

Превью: https://katerinazaber.github.io/itman/checklist/

Структура по макету:
1. Hero (тёмный) + мишка
2. «Скрытые проблемы…» — 4 цифры
3. Интерактивный чек-лист 20 пунктов
4. Результат + мишка + уровни
5. Красный блок + форма заявки

Блоки «Как проходит аудит» и «Что мы проверяем» не делаем.
