# Конструктор персонального PDF-отчёта ROI

Открыть локально: `landing/home-with-calc/roi-report/index.html`  
Превью на GitHub Pages: https://katerinazaber.github.io/itman/home-roi/report/

Модель расчёта — **Base 2026**, та же, что в лид-магните (`roi-embed.js` /
`design-preview.html`) и в `ITMen_ROI_Model_2026.xlsx`. Формулы синхронизированы
в `report-engine.js`.

## Режим менеджера (по умолчанию)

Слева — панель параметров, справа — живой предпросмотр отчёта с графикой. Поля меняются → отчёт пересобирается онлайн.

1. Введите данные клиента:
   - компания;
   - устройств в ИТ-инфраструктуре;
   - из них ПК и серверы (можно оставить пустым — посчитается как ~80%);
   - виртуализация серверов (небольшая часть / примерно половина / большинство);
   - сотрудники учёта техники и лицензий, FTE (0 = автооценка по масштабу);
   - % продления лицензий и % докупки нового ПО (от оценённого бюджета).
2. Проверьте отчёт справа.
3. **Скачать PDF** — файл сохраняется автоматически (без диалога печати).

Эти же значения (кроме компании) обычно уже есть в заявке клиента из
лид-магнита — в скрытом поле `roi_summary` («Данные расчёта»).

## Ссылка для клиента

Кнопка **«Ссылка для клиента»** копирует URL с `?view=report` — открывается только отчёт, без панели менеджера.

Пример:

```
...?company=Acme&devices=2000&compute=1600&virt=high&fte=2&extend=60&buy=20&view=report
```

Параметры:

| Параметр | Значение |
|---|---|
| `company` | название компании клиента |
| `devices` | всего устройств в ИТ-инфраструктуре |
| `compute` | из них ПК и серверов (можно не указывать) |
| `virt` | `low` / `mid` / `high` — доля виртуализации серверов |
| `fte` | сотрудники учёта техники и лицензий (0 = автооценка) |
| `extend` | % бюджета на ПО, который пойдёт на продление лицензий |
| `buy` | % бюджета на ПО, который пойдёт на докупку нового ПО |

Рабочая ссылка менеджера (с панелью) — без `view=report`.

## Файлы

| Файл | Роль |
|------|------|
| `index.html` | Макет отчёта + панель параметров |
| `report-engine.js` | Формулы модели Base 2026 + банк текстов |
| `report-pdf.js` | Экспорт в PDF (A4) через html2canvas + jsPDF |
| `report-pptx.js` | Экспорт в PowerPoint (pptxgenjs) |

## Связь с формой Taptop

Менеджер открывает отчёт по ссылке с параметрами выше или переносит цифры из
поля `roi_summary` заявки (устройства, ПК/серверы, виртуализация, FTE учёта,
% продления/докупки, экономия, ROI, окупаемость — там уже есть весь расчёт
калькулятора). Следующий шаг автоматизации: по заявке автоматически собирать
такую ссылку / PDF и слать на e-mail (отдельная задача).

## Важно про цифры

Экономия года 1 = сумма четырёх направлений (лицензии, техника, труд команды
учёта, полнота учёта активов) — не «обратный» ROI от стоимости ИТМен.
Инвестиции года 1 = лицензия ИТМен на парк устройств + внедрение; ROI считается
за 3 года. Доли консервативные — ориентир для лид-магнита и предварительного
обоснования, не гарантия.
