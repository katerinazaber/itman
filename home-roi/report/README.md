# Персональный отчёт ROI + чек-лист

Превью: https://katerinazaber.github.io/itman/home-roi/report/  
Калькулятор (без квиза): https://katerinazaber.github.io/itman/home-roi/calc-preview.html

## Идея

Длинный квиз в калькуляторе убран. В **отчёте** — кликабельный чек-лист из PDF  
«Бесплатный чек-лист для проверки ИТ-инфраструктуры» (20 пунктов, Да / Средне / Нет).

1. Масштаб парка → ориентир экономии / ROI / окупаемость  
2. Чек-лист → балл /40 и слабые пункты  
3. Рекомендации и аргументы для **финансов / ИБ / руководства** из ответов «Нет» и «Средне»

## Файлы

| Файл | Роль |
|------|------|
| `index.html` | Макет отчёта + UI чек-листа |
| `checklist-data.js` | 20 пунктов + скоринг + тексты рекомендаций |
| `report-engine.js` | Формулы ROI по масштабу |
