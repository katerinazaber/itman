# Персональный PDF-отчёт ROI (макет)

Открыть локально: `landing/home-with-calc/roi-report/index.html`  
Превью на GitHub Pages (после пуша): https://katerinazaber.github.io/itman/home-roi/report/

## Что внутри

1. **Те же вводные**, что в лид-магните: рабочие места, ИТ-команда, бюджет на ПО.
2. **Прозрачный расчёт** по трём направлениям из «Обоснование ИТМен»:
   - ПО / лицензии
   - оборудование
   - трудозатраты ИТ
3. **Персонализация** рекомендаций и аргументов (руководство / финансы / ИБ) по масштабу и доминирующему рычагу экономии.
4. Блок **ITIL 4 Foundation + РИТМ** (практики из БЗ; устав: https://public.ritm.digital/project-definition/ustav-proekta).
5. **Выгрузка PDF** — кнопка «Скачать PDF» → печать браузера → «Сохранить как PDF».

Справка: `docs/ritm-itil-roi.md`, PDF `ITIL_Foundation_ITIL_4_Edition_2.pdf`.

## Связь с формой Taptop

Сейчас менеджер может открыть отчёт по ссылке с параметрами:

```
...?company=Acme&wp=750&it=40&budget=25000000
```

Поле `roi_summary` в заявке уже содержит ответы калькулятора — следующий шаг автоматизации: по заявке собирать такую ссылку / PDF и слать на e-mail (отдельная задача).

## Важно про цифры

В макете экономия = сумма трёх баз (не «обратный» ROI от стоимости ИТМен).
